# Study 09 Implementation Plan

**Goal:** Build an offline interactive mechanical hummingbird concept following the supplied article.

**Architecture:** A serverless native web page with procedural Three.js geometry. A pure kinematic model maps one crank phase and design parameters to every pose and readout. The tour and manual controls share this state, and `renderAt(t)` provides deterministic frame capture.

**Tech Stack:** JavaScript modules, Three.js 0.187.0, esbuild 0.28.2, HTML, CSS and Canvas/SVG.

## Confirmed design

The user authorized an original mechanism. Use an open metal rib frame, graphite vanes, translucent wing membranes and orange working parts in a pale studio. The interface is flat, with a full desktop console and a responsive phone layout. The user subsequently requested English throughout and removal of the earlier project name; the page is now titled Study 09.

Alternatives considered: electromagnetic direct drive lacks a readable mechanical transmission; compliant biomimetic structures complicate constraint explanation. A slider-crank with paired rack-and-pinion wing roots provides a closed-form model driven by one phase.

## Model and limits

All values are concept parameters. Body length: 94 mm; wing-root offset: 12 mm per side; single wing: 98 mm; extended span: 220 mm. Crank radius: 3.8 mm; rod: 18 mm; pitch radius: 4.5 mm.

`slider = r cos(theta) + sqrt(L² − r²sin²(theta))`; `flap = (slider − L)/pitchRadius`.

The sweep is `2r/R = 1.6889 rad = 96.77°`. `28 Hz × 60 × 4 = 6720 rpm`. Feathering uses a phase-linked analytical cam approximation. The tail has a small passive motion driven by the same phase. No measured lift, endurance, temperature or aerodynamic efficiency is claimed.

## Implementation

1. `src/model.js`: parameters, closed-form linkage, velocity, feathering and tour timeline. `src/model.test.js` verifies periodicity, linkage closure, stroke and phase continuity.
2. `src/machine.js`: procedural frame, gears, links, wings, tail and sensor. Support subsystem focus, x-ray and explosion.
3. `src/stage.js`: studio lights, floor shadow, orbit camera, shader precompilation and quality tiers.
4. `src/main.js`, `src/style.css`, `src/template.html`: responsive console, phase charts, linkage schematic, controls and a tour that resumes after 25 seconds without input.
5. `scripts/build.mjs`: bundle a standalone `dist/index.html` under 1 MB. `scripts/serve.mjs`: local preview.
6. Review desktop and phone layouts, every tour beat and the complete motion cycle. Verify wing symmetry and ground clearance in `src/geometry.test.js`.
7. Deliver the local page and offline HTML. Video export and public deployment remain optional; obtain confirmation before publishing.

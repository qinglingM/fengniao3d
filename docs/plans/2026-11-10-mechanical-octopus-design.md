# Mechanical octopus upgrade

User intent: replace the simple hummingbird with a substantially more complex mechanical octopus. Desktop only; mobile layout work is excluded.

Visual direction: ivory ceramic pressure-hull petals, dark load-bearing skeleton, copper transmission hardware, pale turquoise sensor optics. Preserve the existing quiet specimen console.

Structure: eight ten-joint arms with double-row cups, bearing axles, telescoping linkages, and segmented covers; a layered turbine core with eight pump cartridges; separate hull, optics and lower manifold.

Motion: prescribed traveling curvature wave with a 45-degree phase offset per arm; nested joint transforms. The telemetry chart reads the root and sixth joint of arm 01. A separately labeled ideal pump reference retains the slider-crank diagram.

Inspection: assembly, core, arms, hull and manifold selection; shell transparency; progressive explosion; hero/front/side/top/internal cameras; phase scrub, pause, playback speed and frequency.

Performance: batch static core hardware by material and instance matching segment hardware across arms. Preserve automatic quality adaptation.

Verification: solver periodicity and linkage tests, geometry/floor checks, desktop browser interaction checks and assembly/explosion visual review. This is a conceptual visual model rather than a physical underwater robot simulation.
